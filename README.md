# Stock Analysis Project

## Overview

This project is designed to analyze stock data by fetching historical data, calculating technical indicators, and providing a query interface for various stock conditions.

## Setup

1. **Create and activate the virtual environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate

2. **Install the required packages:**
   ```bash
   pip install -r requirements.txt

3. **Configure the project:**
   Edit config/config.py with your database credentials.
